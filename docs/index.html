Clinical LLM Safety Harness

Hallucination detection, citation enforcement, and safeguarding escalation for clinical LLMs.

Static GitHub Pages preview. No backend and no AI model are connected — everything below runs in your browser on pretend data and shows sample outputs only. The real tool is open source and self-hostable: github.com/rtmalikian/clinical-llm-safety-harness

Run the real thing (self-hosted)

Clone the repo and start it with Docker Compose — it ships with an embedded OpenAI-compatible gateway (stub / local model / any OpenAI-compatible upstream), so PHI never has to leave your machine:

git clone https://github.com/rtmalikian/clinical-llm-safety-harness
cd clinical-llm-safety-harness
docker compose up
